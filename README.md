# medium-real-world-example

A full-stack Medium.com clone ("Conduit") built to the [RealWorld](https://codebase.show/projects/realworld) spec, kept in a single repository with both the backend and the frontend.

## Origin

Both the backend and the frontend are forks of implementations listed at [codebase.show/projects/realworld](https://codebase.show/projects/realworld):

- **Backend**: forked from [gothinkster/spring-boot-realworld-example-app](https://github.com/gothinkster/spring-boot-realworld-example-app) (MIT License, see `backend/LICENSE`).
- **Frontend**: to be added.

## Repository layout

| Directory   | Description                                                        |
|-------------|--------------------------------------------------------------------|
| `backend/`  | Spring Boot REST + GraphQL API. See [`backend/README.md`](backend/README.md). |
| `frontend/` | Frontend application (coming soon).                                |
